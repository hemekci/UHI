# UHI — Continuous Morphology Archetypes for Heat Mitigation

Companion repository for the manuscript:

> **Beyond Local Climate Zones: Continuous Morphology Archetypes for Heat Mitigation Across 66 Cities**
> Seyda Emekci, Hakan Emekci.
> Submitted to *Sustainable Cities and Society* (Elsevier).

## Status

The manuscript is **under review**. The full ingest-to-archetypes pipeline,
harmonised patch-level table, and figures will be released here under an open
licence upon acceptance. Until then, this repository is private and intentionally
empty of code and data.

## Planned layout

```

```
